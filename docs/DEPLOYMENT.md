# Deployment Guide - Render Free Tier

## Overview
This guide explains how to deploy the FuelPro Backend to Render using the free tier with a pre-built Docker image from GitHub Container Registry (GHCR).

## Current Status
✅ Docker image built: `ghcr.io/fuel-pro/fuel_app_mobile/fuel-backend:latest`
✅ Backend CI: Passing
✅ Render.yaml: Configured

## Prerequisites
- GitHub account with access to `fuel-pro/FUEL_APP_MOBILE`
- Render account (sign up at https://render.com)

## Step 1: Make Docker Image Public

Before deploying to Render, the Docker image must be public:

1. Go to: https://github.com/orgs/fuel-pro/packages/container/fuel-backend
2. Click **Package Settings** (right side)
3. Scroll to **Danger Zone** → **Change visibility**
4. Click **Change to public**
5. Confirm

## Step 2: Deploy to Render

### Option A: Connect via Render Blueprint (Recommended)

1. Go to https://dashboard.render.com/blueprints
2. Click **"New Blueprint Instance"**
3. Connect your GitHub repository: `fuel-pro/FUEL_APP_MOBILE`
4. Render will detect `render.yaml` automatically
5. Click **"Apply"** to deploy

### Option B: Manual Deployment

1. Create a new **Web Service** on Render
2. Select **Docker** as the environment
3. Enter the image URL: `ghcr.io/fuel-pro/fuel_app_mobile/fuel-backend:latest`
4. Configure:
   - Region: Oregon (or closest to you)
   - Instance Type: Free
   - Port: `10000`
   - Health Check: `/`

### Environment Variables (set in Render dashboard)

| Key | Value | Notes |
|-----|-------|-------|
| `NODE_ENV` | `production` | Required |
| `PORT` | `10000` | Must match Dockerfile EXPOSE |
| `JWT_SECRET` | Generate secure value | Auto-generated by Render |

## GitHub Actions Workflow

The repository has automated workflows:

- **Build Docker Image**: `.github/workflows/build-docker.yml` - Manually triggerable
- **Deploy Backend to Render**: `.github/workflows/deploy-container.yml` - Triggers on `backend/` changes

To rebuild the Docker image:
1. Go to Actions tab
2. Select "Build Docker Image"
3. Click "Run workflow"

## Health Check Endpoint

The backend provides a health check at `/health` which returns:
```json
{"status":"ok","timestamp":"..."}
```

## Free Tier Limitations

- Service sleeps after 15 minutes of inactivity (cold start ~30 seconds)
- 750 hours/month free (enough for one service running 24/7)
- No persistent disk storage (SQLite data in-memory)

## After Deployment

Once deployed, your backend will be available at:
```
https://fuel-pro-backend-v2.onrender.com
```

Update your mobile app's API endpoint to point to this URL.

## Troubleshooting

### Image Pull Issues (403/404)
If Render can't pull the image:
1. Ensure the GHCR package is set to **public** (see Step 1)
2. Verify the image tag exists: `ghcr.io/fuel-pro/fuel_app_mobile/fuel-backend:latest`

### Cold Start Issues
The free tier spins down after 15 minutes. First request after idle will take ~30 seconds.

### Database Persistence
SQLite is in-memory by default. For persistence:
1. Mount a persistent disk in Render
2. Or use a persistent database service
